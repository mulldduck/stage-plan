# STAGE PLAN (스테이지 플랜) v2.0
> **공연·행사 일정관리 및 직원 자동배정 개인용 스마트 PWA**

STAGE PLAN은 복잡한 공연·행사 일정과 수십 명의 현장 직원 배정 메모를 대조하던 반복 작업을 제거하기 위해 설계된 **1인 관리자 전용 모바일 최우선 웹 애플리케이션**입니다.

사용자가 승인한 **스마트 메모 동기화 4단계 UX**와 **월간 7열 달력 인터페이스**를 100% 충실하게 구현하여, 텍스트 메모 붙여넣기 한 번으로 일정 추출, 매칭 검토, 충돌 해결, 캘린더 반영 및 빈 슬롯 자동배정까지 완벽하게 수행합니다.

---

## 🌟 핵심 기능 요약

### 1. 스마트 메모 4단계 동기화 (Smart Memo Sync)
1. **메모 입력 (Step 1)**: 공연별 메모와 직원별 불가 메모 탭 분리 입력, 예시 자동 불러오기, 입력 글자 수 카운터, 임시저장 지원.
2. **자동 분석 미리보기 (Step 2)**: 공연 일정, 직원 배정, 불가 일정, 확인 필요 건수 통계 카드 및 아코디언 상세 내역 확인.
3. **직원·공연 매칭 검토 (Step 3)**:
   - `자동 매칭 완료` / `검토 필요` / `충돌 해결` 3단계 필터링.
   - 미등록 직원/공연장 선택 및 매핑.
   - 불가 일정 충돌(배정 존재) 시 라디오 옵션(`기존 직원과 연결`, `새 공연 생성`, `무시`) 선택.
4. **캘린더 반영 완료 (Step 4)**:
   - 멱등성(Idempotency) 및 고정(Locked) 배정 보호 기반의 안전한 단일 배치 트랜잭션 적용.
   - 달력 내 `NEW` 배지 강조 및 동기화 결과 상세 바텀 시트 노출.

### 2. 7열 모바일 캘린더 (Calendar)
- iPhone 다크모드 최적화 (`#0B1020` 배경, `#151D30` 카드, `#4169FF` 강조).
- 월 이동 및 빠른 연월 필터 알약 탭 (11월, 12월, 2027 1월 등).
- 다일(Multi-day) 공연 연결 막대 및 당일 개별 일정 칩 표시.
- 날짜 터치 시 당일 공연 리스트, 배정 직원, 시간, 불가 일정 요약 확인.
- 배정 직원 잠금(`Locked`) 토글 지원 (자동배정 및 재동기화 시 보존).
- 플로팅 버튼(`+`)을 통한 즉시 공연 수동 생성.

### 3. 직원 관리 (Staff Management)
- 직원명 및 사번(`STF-xxx`) 실시간 검색, 팀별(운영, 기술, 조명, 하우스, 기획) 필터.
- 신규 직원 등록 및 활성/비활성 즉시 전환.
- 직원별 월간 배정 횟수 실시간 집계.

### 4. 자동배정 엔진 (Auto-Assignment Engine)
- 시간 확정 공연의 미배정 슬롯을 적격 직원으로 자동 충원.
- 활성 직원 여부, 종일 불가/개인 일정 겹침, 공연 간 최소 휴식/이동 간격(0분/15분/30분 설정), 공평 근무 분배 알고리즘 적용.
- 가짜 직원을 절대 임의 생성하지 않으며, 미배정 슬롯에는 명확한 사유 기록.

### 5. 데이터 백업 & 엑셀 호환 CSV 내보내기 (Export & Backup)
- 한글 깨짐 방지 UTF-8 BOM 적용 근무표 CSV 다운로드.
- 전체 데이터 무손실 JSON 백업 및 초기 시안 샘플 복원 지원.

- **Frontend**: React 19, TypeScript, Vite 6, Tailwind CSS 4, Lucide React
- **Testing**: Vitest 4 (25개 필수 도메인 및 무결성 검증 테스트 100% 통과)
- **Persistence**: LocalStorage 기반 오프라인-퍼스트 영구 저장소 + Supabase PostgreSQL RLS 마이그레이션 스키마 완비
- **Design**: iOS 17+ Dark Mode HIG, Safe Area Inset 준수, 44px+ 터치 타겟

## 🚀 실행 및 빌드 방법

### 개발 환경 필수 조건
- Node.js 18+ 및 npm (본 프로젝트는 Node v20.18.1에서 검증 완료)

### 1. 개발 서버 실행
```bash
cd /workspace/stage-plan
npm run dev
```

### 2. 프로덕션 빌드
```bash
npm run build
```
- 빌드 결과물은 `dist/` 폴더에 번들링되어 Cloudflare Pages나 정적 웹 호스팅에 즉시 배포 가능합니다.

### 3. 타입 검사 (TypeCheck)
```bash
npm run typecheck
```

### 4. 25대 필수 자동화 테스트 실행
```bash
npm run test
```

## 🗄 데이터베이스 & Supabase 마이그레이션

운영 시 Supabase PostgreSQL을 연동할 수 있도록 `supabase/migrations/20261112000000_stage_plan_schema.sql`에 다음 항목이 완비되어 있습니다:
- `profiles`, `staff`, `staff_aliases`, `venues`, `events`, `assignments`, `staff_availability_blocks`, `audit_logs` 테이블.
- `auth.uid() = owner_id` 조건의 엄격한 Row Level Security (RLS) 정책.
- 동일 직원의 확정 배정 시간 겹침을 DB 차원에서 원천 방지하는 PostgreSQL `EXCLUDE USING gist` 제약 조건.

## 📱 iPhone 홈 화면 PWA 설치 가이드

1. iPhone Safari 브라우저에서 배포된 STAGE PLAN 주소에 접속합니다.
2. 화면 하단 툴바의 **[공유]** 버튼(네모 위 화살표 아이콘)을 탭합니다.
3. 메뉴 스크롤 후 **[홈 화면에 추가]**를 선택합니다.
4. 홈 화면에 생성된 **STAGE PLAN** 아이콘을 실행하면 브라우저 주소창 없이 네이티브 앱 전체화면으로 실행됩니다.
