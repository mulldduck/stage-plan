# STAGE PLAN 제품 / 기능 명세 v2.0

## 1. 제품 목적과 사용자
- 사용자: 공연·행사에 여러 직원(약 20~100명)을 배정하는 관리자 1명. 직원은 계정을 만들거나 앱을 설치하지 않는다.
- 해결 과제: 다양한 장소/날짜/시간의 중복 공연을 수작업으로 메모와 달력에서 찾아 대조하는 과정 제거.
- 하루 사용 흐름: 달력 확인 → 메모 신규 작성/복사 → 자동 분석 → 직원/공연 검토 → 승인 후 달력 반영 → 빈 슬롯 자동배정 → 필요 시 수동 교체 → 근무표 내보내기.
- iOS 홈 화면 PWA를 우선하며 PC 브라우저에서도 기본 동작.

## 2. 화면 내비게이션
- 하단 4탭: 캘린더 / 스마트 메모 / 직원 / 설정.
- 다크모드 (#0B1020 배경, #151D30 카드, #4169FF 강조).

## 3. 스마트 메모 4단계
1. 메모 입력: 공연 메모 / 직원 메모 토글, 연월 선택, 입력 및 예시 불러오기.
2. 자동 분석 미리보기: 공연, 배정, 불가, 확인 필요 건수 및 상세 내역.
3. 직원·공연 매칭 검토: 자동 매칭 완료, 검토 필요, 충돌 해결 필터 및 수동 선택.
4. 캘린더 반영: 승인된 항목 안전 저장, 달력 이동 및 반영 결과 요약.
